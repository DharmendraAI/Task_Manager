# Task Manager CLI Application

## Overview

Task Manager is a simple command-line application developed using Python.
It helps users manage their daily tasks through a menu-driven interface.

## Features

- Add new tasks
- View all tasks
- Update existing tasks
- Mark tasks as completed
- Delete tasks
- Input validation
- Simple menu-driven navigation

## Technologies Used

- Python
- PyCharm
- Git
- GitHub

## How to Run

1. Open the project in PyCharm.
2. Open `main.py`.
3. Run the program.
4. Select an option from the menu.
